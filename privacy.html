1. 한눈에 보기

  • 가계부·자산 데이터는 사용자의 구글 시트에 있고, 앱은 그 데이터를 사용자의 기기에만 저장해요. 앱 운영자의 서버로는 보내지 않아요.
  • 앱만 사용하기로 시작하면 가계부·자산 데이터는 사용자의 기기에만 저장되고, 로그인 서버도 쓰지 않아요.
  • 로그인 유지를 위해 서버에는 구글 계정 이메일과 암호화된 구글 갱신 토큰만 보관해요.
  • 아이폰·안드로이드 앱의 앱 잠금은 기기의 Face ID·지문·암호 확인 결과(성공/실패)만 받아요. 얼굴·지문 정보는 받거나 저장하지 않아요.
  • 앱의 알림은 휴대폰 안에서 예약돼요. 알림을 위해 서버로 보내는 정보는 없어요.
  • 앱은 사용자가 직접 고르거나 앱에서 만든 시트만 볼 수 있어요(구글 drive.file 권한). 드라이브의 다른 파일에는 접근하지 않아요.

3. 구글 사용자 데이터 이용

앱이 구글 API로 받은 정보는 위 목적(사용자의 시트를 앱 화면에 보여주기, 앱에서 새 시트 만들기)에만 쓰고, 다른 사람에게 판매하거나 제공하지 않아요. 앱의 구글 사용자 데이터 이용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따라요.

4. 처리를 맡기는 곳

5. 계정 삭제와 권한 취소

  • 앱 설정 → 구글 계정 · 시트 → 계정 삭제 (구글 연결 해제)를 누르면 서버의 이메일·토큰이 바로 지워지고 구글 권한도 취소돼요. 기기에 저장된 데이터도 지워져요.
  • 구글 계정 → 서드 파티 연결에서도 언제든 권한을 취소할 수 있어요. 이 경우 서버의 토큰은 다음 요청 때 자동으로 지워져요.
  • 구글 시트 파일 자체는 사용자의 드라이브에 그대로 남아요.
